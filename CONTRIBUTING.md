# Contributing

This is **not** an open-source product dump.

## You can

- Use the official APKs personally
- Experiment with the **bones** and send improvements to those sketches
- Email **sedds89@gmail.com** to request product source access for real contributions

## You cannot

- Expect complete Frankenstein / Victor source here
- Expect Driver, training, datasets, or model stacks
- Republish or resell this work

By opening a PR you agree to the contribution grant in `LICENSE`.
